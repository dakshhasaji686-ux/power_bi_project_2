# Sales Performance Dashboard (Power BI)

## Overview

This project presents a Power BI dashboard for analyzing sales data. It highlights product performance, regional distribution, and sales trends over time.

## Key Insights

* Mouse has the highest total sales, followed by Monitor and Smartphone.
* East region contributes the largest share of sales.
* Electronics category dominates over Accessories.
* Sales peak around mid-year and fluctuate across months.
* Quarter 2 shows the highest performance.
